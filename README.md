# Sobre

O FitSync Web é a plataforma web responsável pelo gerenciamento de:

- alunos
- treinos
- exercícios
- academias
- personais trainers
- acompanhamento de desempenho

- TailwindCSS

# Objetivo

Construir uma plataforma moderna e escalável para gerenciamento fitness integrada com aplicações mobile e backend Spring Boot.

---

# Futuras funcionalidades

- Dashboard analítico
- Controle de alunos
- Gestão de treinos
- Histórico de progresso
- Upload de imagens
- Integração com IA
- Notificações em tempo real
